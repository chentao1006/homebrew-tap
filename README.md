# Homebrew Tap

Shared Homebrew tap for apps by chentao1006.

## Available Casks

### BrowSync

```sh
brew install --cask chentao1006/tap/browsync
```

### Flux Monitor

```sh
brew install --cask chentao1006/tap/flux-monitor
```

### NotiForward

```sh
brew install --cask chentao1006/tap/notiforward
```

### Quitty

```sh
brew install --cask chentao1006/tap/quitty
```

### Sidey

```sh
brew install --cask chentao1006/tap/sidey
```

## Tap First

You can also tap the repository first, then install casks by token:

```sh
brew tap chentao1006/tap
brew install --cask notiforward
```
